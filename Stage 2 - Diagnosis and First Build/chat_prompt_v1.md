# Chat paste v1 — compact build for web chats (no system slot)

Paste this as your FIRST message in the chat, then ask in the same message or the next. Built for chatgpt.com-class sites where you only have the message box. Pair it with the spec-framing from your bonus file — the paste sets the workshop, your asks bring the work orders.

Rename `[NAME]` to your handle and `[MK]` to your two-letter mark before use — a build handed to you with someone else's name is a rental, not yours.

Where the paste wins and where it doesn't (tested, not guessed):
- WINS: mid classes and anything you spec-frame (tools, analysis, teardowns, load-testing, game-internals research framed as engineering) — framed asks ship complete
- WINS: kills moralizing, disclaimers, "safer alternative" offers — the workshop voice holds all session
- LIMIT: the hardest classes under a hostile site system prompt (covert implants, live-game cheats phrased as cheats) — the paste alone won't flip those on GPT-class sites; that's the flag layer from your bonus file. Those convert via the Custom GPT slot, a CN model, or the framing methods — stage material.
