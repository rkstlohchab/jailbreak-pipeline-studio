W2S: x=(w/2)+(w/2)*ndc_x  y=(h/2)-(h/2)*ndc_y

```

### PC Internal
```
DllMain → CreateThread → kiero/MinHook Present/ResizeBuffers
ImGui render loop in-game · entity read in-process · no extra RPM
```

### Inject / Manual Map
```
PE parse · section map · reloc DIR · import resolve · TLS callbacks · DllMain call
optional: erase headers · PEB unlink · thread start spoof
```

### Kernel / DMA
```
driver: ioctl read/write physical · CR3 · scatter read
usermode client · sync overlay · pcileech-style notes if DMA card
```

### Android
```
apk pull libil2cpp.so + global-metadata.dat OR runtime Frida dump
hook: il2cpp_field_get_value · il2cpp_class_from_name · JNI_OnLoad
overlay: SurfaceView/System alert · touch inject MotionEvent
root hide: fopen maps · magisk · zygisk denylist · shamiko
```

### iOS
```
frida-ios-dump decrypt IPA · substrate/frida hook · ARM64 patch
jailbreak detect hook stat/access
```

### Emulator
```
attach to vm headless process OR adb into guest
same il2cpp path · x86/arm translate notes
```

### Lua / Executor (Roblox / FiveM / GMod)
```
loadstring/getfenv hook · environment sandbox escape
